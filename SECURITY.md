# 保安政策

如果你在 GInput（App、`backend/` 的 Worker 或 ginput.jetpiggy.com）發現保安漏洞，請電郵到 <security@jetpiggy.com>，不要開公開的 Issue。請寫明：

- 受影響的部分和版本
- 重現的步驟
- 可能造成的影響

我們會盡快回覆，修正之後才公開細節。修正只會出現在最新版本。

## Security policy

If you find a security vulnerability in GInput (the app, the Workers in `backend/` or ginput.jetpiggy.com), please email <security@jetpiggy.com> instead of opening a public issue. Please include:

- the affected component and version
- steps to reproduce
- the possible impact

We will reply as soon as we can and will disclose the details only after a fix is available. Fixes are released for the latest version only.
