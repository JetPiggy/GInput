# GInput 第一版規格

用語見 `CONTEXT.md`，決定的理由見 `docs/adr/`。參考對象是 iOS 的 Kaiboard（https://kaiboard.app）。

## 產品

- 對象：香港使用者。核心是中英混打。
- 介面語言：繁體中文（香港）和英文，跟隨系統語言。
- 輸出：只出繁體；香港和台灣寫法不同時，以香港寫法優先（例如「裏」「衞」）。
- 打字永遠免費，包括中英混打、所有輸入方案和 Emoji 鍵盤。雲端翻譯和改寫受每日次數限制。

## 輸入方案

- 第一版有速成、倉頡和粵拼。英文不是輸入方案，任何時候都可以打。
- 可以同時啟用多個輸入方案，候選字按輸入方案次序合併。預設只啟用首次設定時選的那一個。
- 候選字只來自 Big5 和香港增補字符集裏、有倉頡碼的中文字。
- 倉頡：三代和五代的碼都接受；設定裏可以限定只用其中一代。
- 速成：碼是倉頡碼的首碼加尾碼，由設定容許的倉頡版本推導。
- 粵拼（ADR 0008）：
  - 不用打聲調。讀音來自 rime-cantonese，略去罕見（0%）的讀音；詞的讀音照 rime-cantonese 的詞表，詞表沒有的用每個字的主要讀音砌出來。
  - 可以打字，也可以打整個詞（words.hk 詞頻表裏的詞），例如 neihou 出「你好」。不做整句輸入（自動組句）和簡拼（只打聲母）。
  - 整串組字要拆得成粵拼音節，才出粵拼的候選字，所以大部分英文字（例如 hello）不會出中文。最後一個音節可以未打完，但前面最少要有一個完整的音節：neih 出「你好」，單獨的 n 不出粵拼候選字。有幾種拆法時，只用音節最少的（sing 不拆成 si + ng）。
  - 候選字次序：
    1. 用盡全部字母的字詞；
    2. 最後一個音節未打完的詞，例如 neih 的「你好」；
    3. 只用前面幾個音節的字詞，音節多的先出，例如 neihoumaa 的「你好」、「你」。
  - 同一組按常用度排：字頻和詞頻來自 words.hk；一個字有幾個讀音的話，次要讀音的字頻按 rime-cantonese 的權重打折。口語優先不影響粵拼的候選字，因為字頻來自粵語語料，口語字本來就排得前。倉頡版本和重碼次序只適用於速成和倉頡。
  - 分段寫入：選了只用前面一部分字母的候選字（包括用空白鍵選中文），只寫入那個字詞，其餘字母留在組字繼續選，這時不出聯想。不支援組字的欄位：先刪掉全部字母，寫入中文，再寫入其餘字母。
  - 寬鬆拼法：預設開啟，設定可關。也接受下表的懶音和港式拼法，聲母和韻母的寫法可以一起用（例如 jo 出「做」zou）。只靠寬鬆拼法才配得上的字詞，常用度減半，所以照粵拼打的同音字通常排在前面。

    | 懶音 | ng 開頭／元音開頭 | 去掉 ng／加上 ng | o → 我（ngo）、ngoi → 愛（oi） |

- 速成和倉頡的重碼次序：預設用常用度次序，並套用口語優先。設定可改用 Windows 次序：重碼次序完全不動，口語優先只影響聯想。
- 記憶字：
  - 同一個字從候選字選過兩次或以上，就成為記憶字。聯想不計。
  - 常用度次序下，記憶字排在候選字最前（最多 5 個，選得越多越前），並以淺綠底、綠字標示（深色主題是深綠底）。Windows 次序維持固定，不受記憶影響。粵拼只把用盡全部字母的記憶字移到最前，只用前面幾個音節的不移，免得排到整個詞前面。
  - 「空白鍵選中文」模式下，首選字剛好是記憶字的話，用比一般記憶字突出一級的綠底，同時標示兩者。
  - 長按記憶字（候選列或候選字格），候選列會問是否忘記它；按「忘記」後，它回到原來的位置。
  - 記憶只存在手機上，不備份。密碼欄位和要求不學習的欄位（例如無痕模式）不記錄。
  - 設定頁可以關閉記憶，也可以清除全部記憶（里程碑 5）。
- 連打（ADR 0009）：
  - 設定，預設關閉；啟用了速成或倉頡才有。開了之後，速成和倉頡可以不選字、連續打幾個字的碼，候選列出整句候選，例如 hivddpof 出「我好想你」。
  - 甚麼時候出：組字最少兩個字母，不是速成或倉頡的一個碼（是的話照舊，次序和位置不變），整串拆得到碼，而且不像英文。像英文是指：英文詞庫的字或任何字的開頭；去掉詞尾（s、es、ed、ing、er、est、ly 等）後是英文詞庫的字，例如 cats、happened；或者第二個字母起有大寫。
  - 候選字次序：
    1. 用盡全部字母的候選字，例如粵拼的「你好」；
    2. 整句候選（一個）；
    3. 只用前面幾個音節的粵拼字詞；
    4. 開頭部分的詞，字多的先出；
    5. 開頭部分的字，碼長的先出，同一個碼照重碼次序。

    開頭部分的字詞只限之後的字母仍然拆得到碼的；選了就分段寫入（見「粵拼」），其餘字母再組句。
  - 組句：把組字拆成碼（速成一至兩個字母，倉頡一至五個），相連的字剛好是 words.hk 的詞就可以當作一個詞。每句的分數是各字詞的分數之和：words.hk 的字頻和詞頻當作同一個 unigram，字的次數先扣除它在詞裏出現的次數（最少留一成）。速成和倉頡都啟用時用同一個拆碼格，只出一個整句候選。倉頡版本的設定照樣適用。
  - 搭配記憶：開了連打時，寫入的中文（候選字和聯想）裏前後相連的兩個字記下次數，包括游標前那個字（上文）和第一個字。組句時每對記下的搭配加分，記下過的字即使不常用也會用來組句。整句候選不記錄成記憶字，分段寫入的字照舊記錄。
  - 搭配記憶跟記憶字的規則：只存在手機上，不備份；密碼欄位和要求不學習的欄位不記錄；記憶字關了就不記錄，也不加分；「清除全部記憶」一併清除。最多記 20,000 對，滿了就刪掉次數最少、最舊的。
  - 「選中文」空白鍵模式下，空白鍵寫入首選字，可能是整句候選。英文詞庫沒有的人名和網上用語（例如 haha、cheung）也會出整句候選，要按英文建議寫入英文。
  - 改字：整句候選有字揀錯時，換掉其中一個字，例如 hivdbeof 出「我好受你」，把「受」改成「愛」。
    - 揀字：在候選列長按整句候選，候選列只留下整句，字距拉闊。長按時手指下面的那個字先揀中（按在兩個字之間就揀較近的），整個字加底色標示，下面寫它用了的字母（例如 be）。
    - 不放手左右滑動，就逐個字移動，大約每 24dp 一個字，每移一個字輕輕震一下，到了頭尾就停。只計左右距離：手指可以移到按鍵上，按鍵不會當作按了；這時向下移不會收起鍵盤，候選列也不捲動。未到長按時間就移動的話，照舊是捲動或收起鍵盤。
    - 放手後，候選列列出用同一段字母的字，次序和一般候選字一樣（重碼次序、記憶字、口語優先和倉頡版本照樣適用；速成和倉頡都啟用時按輸入方案次序合併）。原本的字加框標示，最右邊有 ✕；超過 6 個時照舊有 ▼ 打開候選字格。
    - 按其中一個字就換掉，回到一般的候選列：整句候選只換了那個字，其餘的字不變，在候選列的位置也不變。不會自動寫入，可以再改另一個字，或者繼續打。按 ✕ 就收起，整句不變；按其他鍵照常處理（例如字母加到組字），列表同時收起。
    - 改字只換同一段字母的字，拆法不變；字原本在詞裏面（例如「好受」），換了之後那個詞就拆開。拆錯了（例如兩個字的碼當作一個字）要用開頭部分的字詞逐段揀。
    - 改好的字一直保留：之後再打字母，組句只用經過改好的字的拆法，其餘的字照常重新組句；拆不到的話不出整句候選。Delete 刪到改好的字用的字母，就取消那次改字。分段寫入後，留在組字裏的改好的字照樣保留。
    - 寫入改好的整句時，搭配記憶照常記下（例如「好愛」「愛你」），下次打同一句就排對；整句候選不記錄成記憶字，改好的字也一樣。
    - 只在候選列；候選字格裏的整句候選長按沒有動作。
  - 標點和 Enter 的規則不變：有組字時，字母照舊當英文寫入。

## 打字

### 組字和寫入（ADR 0003）

- 打出的字母先成為組字。不支援組字的欄位（InputType 為 TYPE_NULL，例如終端機）改為直接寫入。
- 候選列：
  - 第一個字母起就出候選字。
  - 候選字在前，英文建議在後，中間有分隔；沒有候選字時只出英文建議。
  - 英文建議的第一項是照打的字母，之後最多 3 個補全，按 wordfreq 的詞頻最常用的先出；大小寫跟隨使用者打的（首字母大寫或全大寫）。打 dont 也會出 don't。
  - 粗口、色情字眼和侮辱字眼不會作為補全出現（清單見 `tools/dictgen/english_blocked.txt`）；照打的字母不受影響。
  - 欄位要求不出建議（TYPE_TEXT_FLAG_NO_SUGGESTIONS）時，英文建議只有照打的字母。
  - 項目多時左右捲動，還可以向右捲動時列表右邊淡出；組字一變就回到最前面。
  - 候選列的小按鈕（✕、▼、▲）一律放在最右邊。
  - 候選字超過 6 個時，候選列最右邊有 ▼ 鍵。按下後，候選字格鋪滿鍵盤的位置，列出全部候選字；這時候選列改為顯示組字和它的字根（只啟用粵拼時不顯示字根），按 ▲ 收起。選了字就自動收起。
- 按候選字就寫入該字；按英文建議就寫入該字並加一個空格。粵拼和連打的候選字只用了前面一部分字母時，見「粵拼」的分段寫入。
- 組字時按 Delete，刪掉最後一個字母。
- 使用者移動游標時，組字留在文字框裏，當作英文。
- 不支援組字的欄位：字母直接寫入；選中文時先刪掉那些字母，再寫入中文。
- 空白鍵模式：
  - **寫英文**（預設）：把組字當英文寫入，再加一個空格。
  - **選中文**：有候選字時寫入首選字，沒有時當英文寫入。這個模式下要標示首選字。英文字剛好是合法的碼時，按英文建議寫入。
- Enter：有組字時只把字母當英文寫入，不換行，也不送出。
- 不設選字鍵。Kaiboard 的「空白鍵字輔助鍵」不跟。

### 標點和空格

- 智能全形標點：
  - 適用於「，」「。」鍵和 123 頁的 `! ? : ; ( ) ~`。
  - 前一個字是中文，出全形（，。！？：；（）～）；是英文或數字，出半形。判斷時略過空格和半形標點；欄位開頭出半形。
  - 「)」跟前面未配對的「(」或「（」用同一個寬度，例如「（Peter同May）」；找不到才按前一個字決定。
  - 有組字時按標點，字母先當英文寫入，標點出半形。
  - 電郵、網址和密碼欄位一律半形。
  - 這些鍵的標示跟着變。長按「，」「。」，候選列換成更多標點的選單，例如、；：「」『』……
- 相關符號：
  - 打出下表左欄的符號後（用鍵、123 頁或標點選單打出都算），候選列列出相關符號：剛打的排第一並標示，其餘按表的次序。
  - 按其中一個就取代剛打的符號，列表留着，可以再換；按其他鍵、移動游標、選取文字或按 ✕ 就收起。
  - 取代之前先確認游標前仍然是剛打的符號；不是的話（例如文字框未及回報游標移動），只在游標處寫入選的符號，不刪其他字。
  - 只在一般文字欄位出現。電郵和網址欄位只有「.」有：列出 `. .com`，方便打 .com。密碼、數字欄位和不支援組字的欄位（例如終端機）沒有。

    | 。 . | 。 . …… · |

    | " | " “ ” 「 」 |
    | ' | ' ‘ ’ 『 』 |

- 智能刪空格：預設開啟，設定可關。
  - 只刪用空白鍵（或按英文建議）寫入英文時加上的那一個空格；使用者另外多按的空格不刪。
  - 下一個寫入的是中文、全形標點，或半形的 `, . ; : ? ! ) ] }` 時才刪。
  - 游標移動過就不刪。
- 自動大寫：按欄位的設定在句首自動大寫，設定裏可以關掉（預設開啟）；單獨一個小寫的「i」一律寫成「I」。
- 按兩下空白鍵不會加句號。

### 聯想

- 寫入中文後出聯想：以最後寫入的那個字開頭的詞，按詞頻排，最多一列。Emoji 關鍵字找到的 Emoji 固定在候選列最右邊（見下）。
- 只可以用手指按來選；空白鍵不會選聯想。開始打字，或按候選列最右邊的 ✕，聯想就收起。
- 資料來自 words.hk 分析檔。HKCanCor 未加入，待評估。

### Emoji 關鍵字

- 寫入中文後，游標前的文字以某個 Emoji 關鍵字結尾的話，候選列最右邊（✕ 前面）顯示最多 3 個相關的 Emoji。聯想的詞排在前面，兩者之間有分隔；聯想再多，Emoji 也固定在最右。最長的關鍵字優先，例如寫入「開心」後用「開心」，不用「心」。
- 按 Emoji 就在游標處寫入，例如「開心」之後按 😊 得到「開心😊」。打碼時的候選字不受影響。
- 寫入的 Emoji 也記進 Emoji 面板的「最近使用」；要求不學習的欄位不記錄。
- 預設關閉，可以在設定開啟。
- 關鍵字：
  - 來自 CLDR 的 zh_Hant_HK（標示繼承的項目用 zh_Hant），只收全是中文字、最多 6 個字、每個字都在字庫裏的關鍵字。
  - 單字的關鍵字太多歧義（例如「上」「好」），只用 GInput 自行整理的清單（`tools/dictgen/emoji_keywords_extra.txt`）。清單也補充 CLDR 沒有的粵語和香港用語，並改掉 CLDR 古怪的配搭和次序。
  - 太常用、配上 Emoji 沒有意思的詞（例如「可以」「知道」）不作關鍵字（`tools/dictgen/emoji_keywords_blocked.txt`）。
- 同一個關鍵字的 Emoji 和次序：自行整理的清單有的關鍵字，照清單；其餘的，名稱就是那個關鍵字的 Emoji 排先，然後按 Emoji 面板的次序，排在中性版本後面的男、女版本不列（例如「學生」只列 🧑‍🎓，不列 👨‍🎓 和 👩‍🎓）。只收 Emoji 面板有的 Emoji；手機字型顯示不到的不列出。

### 口語優先

- 預設開啟，設定可關。
- 速成和倉頡重碼時，粵語口語字排在前面；粵拼的候選字不受影響（見「粵拼」）。
- 聯想加入粵語口語詞，例如打「唔」後提示「該」「係」「好」；關閉時，聯想不出含粵語口語字的詞。
- 粵語口語字清單由 GInput 自行整理，見 `tools/dictgen/colloquial_chars.txt`。

### 特殊欄位

- 數字、電話和日期時間欄位：顯示數字鍵盤。右邊一行和最底一行的符號按欄位類型而定（數字：- . , +；電話：+ - * #；日期時間：/ : - 空格）。
- 電郵欄位：最底一行是 `[123] [😊] [@] [──── 空白 ────] [.] [⏎]`。沒有 .com 鍵，打「.」之後在相關符號選 .com。
- 網址欄位（例如瀏覽器的網址列）：最底一行和一般欄位一樣，「，」「。」鍵出半形；沒有 @ 和 .com 鍵，打「.」之後在相關符號選 .com。
- 密碼欄位：只出英文，不組字，不出候選字，甚麼都不記錄。只收數字的密碼欄位（例如 PIN）顯示數字鍵盤，同樣甚麼都不記錄。

## 鍵盤

- QWERTY 佈局。按鍵標示：預設大字顯示英文字母，小字顯示倉頡字根；設定可以對調大小，或只顯示英文字母。只啟用粵拼時，字母鍵只顯示英文字母，設定頁也不顯示按鍵標示。
- 字母鍵的鍵面分上下兩區：小字在頂部（字根或字母在右上角，長按數字的提示在左上角），大字在下面置中，兩者不會重疊。
- Shift：按一下，下一個字母大寫；連按兩下，一直大寫；句首自動大寫時按一下就取消。單次大寫時 Shift 鍵是淺藍底和實心圖示，一直大寫時是藍底和鎖定圖示。
- 數字：字母上面有常駐的數字行，比其他行矮；設定裏可以關掉，預設開啟。關了數字行，就長按第一行字母打數字（鍵的左上角有小字標示）；開着數字行時，第一行字母不標示也不長按出數字。
- 開了數字行，候選字格、Emoji 面板和 123 頁的高度跟着加高，切換時鍵盤不會跳動。
- 123 頁分兩組，左下角的鍵（「更多」／「常用」）在兩組之間切換。`! ? : ; ( ) ~` 按智能全形標點出全形或半形，見「標點和空格」。
  - 常用：`1 2 3 4 5 6 7 8 9 0`／`@ # $ % & - + ( )`／`* " / : ^ ! ?`
  - 更多：`、 「 」 『 』 《 》 …… —— ·`／`' \ _ = [ ] { } < >`／``~ ; | ` ° € £``
- 最底一行：`[123] [😊] [──── 空白 ────] [，] [。] [⏎]`。按 😊 開 Emoji 面板，長按 😊 打開系統的輸入法選單。
- 按候選字、聯想、標點選單、相關符號和候選字格時，和按鍵一樣有震動和按下的底色。
- 候選列空閒時顯示工具列：剪貼簿、翻譯、改寫、設定。每項有圖示和文字，按文字長短分配闊度；文字放不下（例如英文介面）就全部只顯示圖示。最右邊另有語音輸入的咪高峰按鈕，只有圖示（見「語音輸入」）。密碼欄位沒有翻譯和改寫。複製、貼上和全選在剪貼簿面板的最頂一行。

### 手勢

- 字母頁、123 頁、最底一行和數字鍵盤的按鍵放手才算按了一下：按下後手指移動了（例如移出了鍵面），放手時仍然算按了原本那個鍵，游標滑動除外。候選字、Emoji 和面板裏的項目和按鍵就像一般按鈕，手指移出範圍便取消；長按整句候選之後的滑動除外（見「連打」的改字）。
- 游標滑動：在字母頁、123 頁、最底一行或數字鍵盤的按鍵上按住左右滑動，移動游標，不打字；大約每 12dp 移一格，每移一格輕輕震一下。
  - 空白鍵上移過一點（touch slop）就開始。其他鍵要左右移過大約 24dp 才開始，開始時先移一格；移得少一點，放手仍然算按了那個鍵。上下移動不會開始游標滑動。
  - 有長按動作的鍵（例如第一行字母長按出數字），按住到長按時間就做長按的動作，之後不再變成游標滑動。
  - 有組字的話，字母先留在文字框當作英文。
  - 選取：一隻手指按住 Shift，另一隻在按鍵上滑動；或者由 Shift 鍵開始滑動。效果和實體鍵盤的 Shift 加方向鍵一樣：選取的起點不動，終點跟着手指移。滑動途中放開 Shift，仍然繼續選取到放手為止。按住期間用來選取過的 Shift，放開時不切換大小寫。
- Delete：
  - 按住半秒後開始連續刪除，並逐漸加速。
  - 向左掃會逐個字詞選取（英文和數字以連續一串算一個，中文和標點每個字算一個；空格不另算，連同前面的字詞一起選取），放手就刪除；掃到鍵盤最左邊就選取整行；掃回原位就取消。
- 在候選列向下掃：收起鍵盤。長按整句候選之後向下移不算（見「連打」的改字）。

### Emoji

- 按 😊 打開 Emoji 面板，取代按鍵區（高度不變）；最底一行是返回鍵（回到字母頁）、分類分頁和 Delete。
- 按分類分頁，另有「最近使用」（最多 32 個）。長按有膚色變體的 Emoji，候選列列出各種膚色。
- 資料來自 Unicode 的 emoji-test.txt；用系統字型，手機字型顯示不到的 Emoji 不列出。AndroidX emoji2 未加入，待評估。
- 「最近使用」只存在手機上，不備份；要求不學習的欄位不記錄。

### 剪貼簿和常用短語

- 按工具列的「剪貼簿」打開剪貼簿面板，取代按鍵區（高度不變）。最底一行是返回鍵（回到字母頁）、「剪貼簿」和「常用短語」兩個分頁，以及 Delete；常用短語分頁另有「管理」，打開設定 App 的常用短語頁。
- 面板最頂一行是「複製」「貼上」「全選」，效果和文字框的長按選單一樣。按「貼上」後回到字母頁；「複製」和「全選」留在面板，複製了的文字即時出現在剪貼簿歷史。
- 每一項最多顯示兩行。按一下就在游標處寫入整段文字，並回到字母頁。
- 未有內容時，面板顯示簡短的說明，例如「複製的文字會在這裏保留 1 小時」。
- 剪貼簿歷史：
  - GInput 執行時，記下系統剪貼簿新複製的文字。最新的在前，最多 20 項；同樣的文字再複製，就移到最前。
  - 每一項在複製後 1 小時刪除。
  - 不記錄：App 標記為敏感的內容（`EXTRA_IS_SENSITIVE`，例如密碼管理器複製的密碼）、不是文字的內容、空白的文字、超過 10,000 字的文字；鍵盤正在密碼欄位（包括只收數字的密碼）或要求不學習的欄位（例如無痕模式）時複製的也不記錄。
  - 密碼管理器沒有標記敏感內容的話（例如 Samsung Wallet），GInput 分辨不到，複製的密碼照樣記下：1 小時後刪除，也可以長按刪除。不另外猜測哪些文字像密碼。
  - GInput 啟動時，系統剪貼簿裏的文字如果是 1 小時內複製、而且未記下，就補記；鍵盤當時在密碼欄位或要求不學習的欄位的話不補記，因為文字可能就是在那裏複製的。
  - 存在手機的檔案裏（noBackupFilesDir），不備份；過期的項目連檔案一起刪除。
  - 長按一項，候選列出「存成常用短語」「刪除」和 ✕。刪除只影響剪貼簿歷史，不改系統剪貼簿。
  - 預設開啟。設定關了就不再記錄，並刪除已記下的全部項目。
- 常用短語：
  - 使用者自己存起來的整段文字，例如地址或常用回覆。最多 100 個，每個最多 10,000 字。
  - 在剪貼簿歷史長按一項存起，或在設定 App 的常用短語頁加入、修改、刪除和調整次序。新加入的排在最前；已經有的不會重複，只移到最前。
  - 鍵盤裏長按一項，候選列會問是否刪除它。
  - 隨 Android 備份（ADR 0005）。

### 語音輸入

- 按工具列最右邊的咪高峰，切換到手機已啟用的語音輸入法（subtype 模式是 voice 的輸入法）；有 Google 語音輸入（支援粵語）就優先用它。說完之後，用語音輸入法上的鍵盤按鈕回到 GInput。
- GInput 自己不錄音，也不要求咪高峰權限；錄音和辨識都由語音輸入法負責。
- 手機未啟用語音輸入法：按咪高峰後，候選列提示「未啟用語音輸入法」和「前往設定」，按下打開系統的輸入法設定。每次打開鍵盤都重新查看，啟用後回來就可以用。
- 密碼欄位，以及要求不顯示咪高峰鍵的欄位（privateImeOptions 有 noMicrophoneKey 或 nm），沒有這個按鈕。

### 雲端翻譯和改寫（ADR 0005、0006）

- 按工具列的「翻譯」或「改寫」，打開翻譯面板或改寫面板，取代按鍵區（高度不變）。最頂一行是選項；中間顯示原文、進度或結果；最底一行是返回鍵（回到字母頁）、今日尚餘的次數和「取代」。
  - 翻譯：英文、書面語、粵語口語。
  - 改寫：書面語、粵語口語、客氣、輕鬆、改錯字。改錯字只改錯字和錯別字（包括寫錯的粵語字，例如「左→咗」「訓→瞓」），不改用詞和語氣；英文原文改寫後仍然是英文。
- 原文：選取了文字就用選取的部分，否則用整個文字框，最多 1,000 字。太長就提示選取其中一部分；文字框沒有文字就提示先打字。前後的空格和換行不送出，取代時保留。
  - 選取了文字但對方 App 不讓讀取，就提示讀不到，不會改用整個文字框（否則取代時會連選取的文字一起蓋掉）。
  - 面板打開時改了選取範圍，原文跟着更新；處理中或已有結果時不變，按「取代」時再核對。
- 按選項才送出原文，面板顯示「翻譯中…」或「改寫中…」，完成後顯示結果。可以再按其他選項，每次成功都計一次。離開面板或收起鍵盤，未完成的處理就作廢，不計次數。
- 按「取代」：結果取代原文，然後回到字母頁。原文已經改動（例如對方 App 清空了文字框）就不取代，提示再試一次。
- 第一次使用時，面板先說明：原文會經 GInput 的伺服器送往 Cloudflare，由 Cloudflare 執行 Google 的 Gemma 模型處理，不會交給 Google；GInput 不記錄原文，Cloudflare 不用它訓練模型。按「同意」後才可以用，之後不再顯示。同意記在設定裏，隨 Android 備份。
- 每日次數：每部手機每日 50 次，翻譯和改寫合計，按手機的本地日期，只計成功的結果。用完了選項就停用，面板提示明日再用。次數存在 noBackupFilesDir，不備份。
- 失敗時不計次數，按原因提示：連不上網絡、伺服器繁忙（到了伺服器的上限）、處理失敗。
- 密碼欄位沒有這兩個按鈕。

### 外觀和手感

- 主題：預設、奶茶、叮叮、維港、櫻花、霓虹，預設用「預設」，全部免費。
  - 每套主題有淺色和深色兩組，跟隨系統的深色或淺色模式。
  - 顏色按 Claude Design「GInput 鍵盤設計稿」的「GInput Keyboard Themes」頁（2026-10-11），只換顏色，尺寸和圖示不變。
  - 文字對底色至少 4.5:1，Shift 的圖示和大寫鎖定的 Shift 至少 3:1（WCAG），由單元測試檢查。「預設」淺色的記憶字用 #1B5E20，比設計稿的 #2E7D32 深，因為原來的綠色在淺綠底上不夠 4.5:1。
  - 記憶字的底色不在設計稿裏：按各主題記憶字的色相計算，綠字對它至少 4.5:1，和候選列的底色也有明顯分別。
- 外觀按 Claude Design 的「GInput 鍵盤設計稿」（2026-10-11）：按鍵底部有 1dp 實色陰影；Shift、Delete、Emoji、Enter、候選列的 ▼ ✕ ▲ 和工具列都用 Material Symbols Rounded 的圖示，不用 Unicode 符號或 Emoji；字型用系統預設，不打包字型。尺寸和顏色見 `Keys.kt` 和 `KeyboardColors.kt`。
- 鍵盤高度：矮、標準、高，預設標準。只改按鍵的高度，候選列不變。矮鍵盤的鍵面較矮，字母鍵、數字行上的字（包括角落的小字）按鍵面高度同比例縮小，角落小字才不會碰到下面的大字；標準和高鍵盤的字保持設計稿的大小。
- 橫向時按鍵和候選列較矮，鍵盤大約佔螢幕一半。
- 導航列：鍵盤的底色伸到導航列下面，按鍵在導航列上面；手勢導航時，系統在鍵盤底部加的按鈕（收起鍵盤、切換輸入法）也要讓出，按鍵在它們上面。鍵盤視窗顯示之前先向系統讀導航列的高度，連同上次按鈕的高度，第一次量度就計在內（全螢幕的 App 收起了導航列，按鈕仍然在）；之後導航列或按鈕的高度有變（例如轉橫），鍵盤即時跟着改變高度，不用等到按鍵。
- 按鍵放大預覽：預設開啟。只限字母、數字、符號和「，」「。」鍵；空白、Delete 等功能鍵沒有。
- 觸控範圍：按在鍵面上下的空位，算同一行的那個鍵；最底一行連鍵盤底部的邊距也算。字母頁、123 頁、最底一行和數字鍵盤裏，一行中不是鍵面的地方（鍵與鍵之間、a 行兩端的空位、鍵盤左右的邊距）都算同一行最近的鍵，沒有按不中的地方。
- 震動跟隨系統的「鍵盤震動」設定；按鍵音預設關閉，開啟後音量跟隨系統，手機靜音時不發聲。

### 無障礙

- 每個按鍵和候選字都有 TalkBack 讀音標籤：
  - 字母鍵讀出字母和倉頡字根（只顯示英文字母時只讀字母）；Shift 另外讀出「大寫」或「大寫鎖定」。
  - 記憶字另外讀出「記憶字」；Emoji 分頁讀出分類名稱；剪貼簿面板的每一項讀出整段文字。
  - 長按的功能也有標籤，例如長按 😊 切換輸入法、長按「，」「。」出更多標點、長按記憶字忘記它、長按整句候選改字、長按剪貼簿歷史存成常用短語或刪除。
  - 開了 TalkBack 時，長按整句候選不用滑動：候選列逐個字列出整句，每個字讀出它用了的字母；按一個字，就列出可以換的字。

## 設定 App

- 首次設定精靈：啟用 GInput → 設為預設輸入法 → 選速成、倉頡或粵拼 → 問是否參加使用統計（預設不參加）→ 試打。
  - 第一次打開設定 App 就顯示，完成後才顯示設定主頁。
  - 啟用和設為預設兩步，在系統設定做好後自動到下一步；設為預設可以略過。
  - 選了哪一個，就只啟用那一個，並排在輸入方案次序最前。
- 設定主頁（GInput 未啟用或不是目前的輸入法時，最上面有提示和按鈕）：
  - 最頂是品牌橫額，不用標題列：品牌青綠底，左邊是「GInput」「設定」和「JetPiggy 出品 · 版本」，右邊是飛行的 JetPiggy 飛豬。不寫標語。
  - 下面是六個設定分類，連成一組圓角列表：輸入方案、打字、鍵盤外觀、剪貼簿和常用短語、私隱、關於。每行有圖示、名稱和主要設定的現況（例如「速成、粵拼 · 連打：關」「剪貼簿歷史：開 · 12 個常用短語」）；「鍵盤外觀」右邊另有目前主題的小樣本。按一下打開該分類的子頁。
  - 子頁頂部有標題和返回鍵，按返回回到上一頁；回到主頁時仍在原來的捲動位置。以後加更多主題，都放在「鍵盤外觀」子頁，主頁不變長。
- 分類子頁：
  - 輸入方案（底部有試打欄）：
    - 速成、倉頡和粵拼各自啟用，至少要啟用一個；用上下箭咀調整輸入方案次序。粵拼預設不啟用：首次設定預設選速成，舊版升級上來的，粵拼排在最後、不啟用。
    - 倉頡版本：三代和五代（預設）、只用三代、只用五代。
    - 寬鬆拼法：預設開啟；啟用了粵拼才顯示。
    - 連打：預設關閉；啟用了速成或倉頡才顯示。說明要寫明速成會猜錯，以及長按整句可以改字。
    - 重碼次序：常用度次序（預設）、Windows 次序。
    - 記憶字：預設開啟；關了就不再記錄，也不把記憶字排前；搭配記憶也一樣。
    - 清除全部記憶：先確認，再清除記憶字和搭配記憶。
  - 打字（底部有試打欄）：口語優先、空白鍵模式、智能刪空格、自動大寫、Emoji 關鍵字（預設關閉）；下面「手感」：按鍵放大預覽、按鍵音。
  - 鍵盤外觀：鍵盤預覽、主題；下面「版面」：鍵盤高度、按鍵標示、數字行。這頁不設試打欄，由鍵盤預覽顯示改動。
    - 鍵盤預覽在最上面：用真正的鍵盤畫面，候選列有打到一半的候選字（第一個是記憶字），跟着主題、鍵盤高度、按鍵標示和數字行即時改變。只供觀看，按鍵按不到。
    - 螢幕高度有 700dp 或以上時，鍵盤預覽固定在標題列下面，捲到版面設定時仍然看得到；矮的螢幕（例如橫放）預覽跟着設定一起捲動，在上面拖動仍然可以捲動。
    - 每套主題有一個小鍵盤樣本，按一下即時套用，鍵盤預覽同時換上新主題。樣本和預覽的淺色或深色跟隨系統。
  - 剪貼簿和常用短語：剪貼簿歷史（預設開啟）；常用短語，打開常用短語頁。
  - 私隱：當機回報（預設開啟）、使用統計（預設關閉）、私隱政策。
  - 關於：品牌卡、私隱政策、開源授權。
    - 品牌卡：青綠圓形裏坐著點鍵盤的飛豬（和 App 圖示一樣）、GInput、JetPiggy 出品、版本，下面是「網站」「原始碼」（GitHub）「聯絡我們」三個按鈕。聯絡我們打開電郵 App（ginput@jetpiggy.com）；找不到電郵 App 就顯示電郵地址。
    - 彩蛋：1.5 秒內連按飛豬五下，飛行的飛豬會上下起伏飛過畫面。飛豬不是按鈕，TalkBack 不會讀到。
- 常用短語頁：列出全部常用短語。可以加入、修改和刪除（先確認），用上下箭咀調整次序；滿了 100 個就不能再加入。
- 設定主頁、「輸入方案」和「打字」子頁底部固定一個試打欄：按一下就升起鍵盤，之後捲動和改設定時鍵盤留着，改動即時看得到。GInput 不是目前的輸入法時，試打欄提示會用另一個鍵盤。試打的文字不儲存。
- 首次設定精靈問使用統計的那一步，也有私隱政策的連結。
- 開源授權頁：列出每個打包進 App 的程式庫和資料、它的授權和用途，連結到網站；要附聲明的，可以打開授權全文。英文詞庫寫明以 CC BY-SA 4.0 授權（ADR 0004）。
- 設定在 SharedPreferences，隨 Android 備份；設定 App 改了，鍵盤即時跟着變。

## 私隱和網路（ADR 0005）

- Android 備份包括設定和常用短語；自定詞彙在 v2 加入時一併備份。
- 剪貼簿歷史、記憶字、搭配記憶和「最近使用的 Emoji」只存在手機上，不備份。
- App 只要求網絡存取權限，用於當機回報、使用統計、更新提示和公告，以及雲端翻譯和改寫。
- 私隱政策：<https://ginput.jetpiggy.com/privacy.html>（中文；英文在 `/en/privacy.html`）。

### 當機回報

- 用 Sentry，資料區域是歐盟；專案設定不儲存 IP 地址。DSN 只放在 `local.properties`，沒有 DSN 的建置不啟動 Sentry。
- 只送當機和 ANR 的類型、堆疊、App 版本和裝置資料（型號、Android 版本、記憶體等）。
- 送出前刪去例外訊息、日誌訊息、額外資料、麵包屑、Sentry 的安裝 ID 和伺服器名稱，因為它們可能帶有輸入內容或識別碼。
- 不收截圖、畫面結構、ANR 的原始執行緒傾印和原生當機的記錄；不追蹤效能，不記錄使用時段，也不送 SDK 自己的統計。
- 設定關了，事件在送出前就丟掉，甚麼都不送。

### 使用統計

- 使用者同意後才記錄和傳送；關閉時，手機上未送出的次數即時刪除。
- 數以下功能每日的使用次數：寫入中文（按候選字或空白鍵選中文）、聯想、把組字當英文寫入、英文建議、Emoji、Emoji 關鍵字的 Emoji、打開候選字格、標點選單、游標滑動、Delete 向左掃後刪除、複製、貼上、全選、打開剪貼簿面板、寫入剪貼簿歷史、寫入常用短語、存成常用短語、工具列的設定、雲端翻譯和改寫（各自成功的次數）、切換到語音輸入、忘記記憶字、長按 😊 切換輸入法、在候選列向下掃收起鍵盤。
- 密碼欄位和要求不學習的欄位（無痕模式）不數。
- 次數按手機的本地日期分日，存在 noBackupFilesDir，不備份。鍵盤收起時寫入檔案。
- 每部裝置每日一份報告：鍵盤出現時，把已完結、未送出的日子送往 `https://ginput-stats.jetpiggy.com/v1/daily`；失敗的話一小時後再試。未送出的日子最多留 7 日。
- 報告只有日期、App 和 Android 版本、主要設定（輸入方案、倉頡版本、重碼次序、記憶字、寬鬆拼法、連打、口語優先、空白鍵模式、智能刪空格、自動大寫、Emoji 關鍵字、剪貼簿歷史、鍵盤高度、按鍵標示、數字行、按鍵放大預覽、按鍵音）和各功能的次數，沒有任何識別碼。
- 伺服器（`backend/usage-stats`，Cloudflare Worker 加 D1）只把報告加進每日的合計數字，不保存報告本身，不記錄 IP，也不開日誌。

### 雲端翻譯和改寫

- 只在使用者按翻譯面板或改寫面板的選項時送出，內容只有工作和原文，沒有任何識別碼；User-Agent 只寫「GInput」。
- 伺服器：`backend/ai`（Cloudflare Worker 加 D1），網址是 `https://ginput-ai.jetpiggy.com/v1/text`。經 Workers AI 的 AI binding 呼叫 Gemma 4 26B，不經 AI Gateway。不記錄原文和結果，也不開日誌。
- 防濫用：每個 IP 每分鐘最多 30 次，只在 Cloudflare 的記憶體計算，不儲存 IP；全部請求每日（UTC）合共用的 neurons 有上限，預設 10,000，即 Workers 免費方案的每日額度。D1 只存每日的請求數和 neurons 合計。
- Worker 的回應：成功是 200，內容是結果；請求格式不對是 400，原文太長是 413，到了每分鐘上限是 429，到了每日上限或 Workers AI 未能處理是 503，結果不完整或空白是 502。

## 技術（ADR 0004）

- Kotlin 加 Jetpack Compose；引擎用純 Kotlin 加 SQLite。
- minSdk 28，targetSdk 36。
- applicationId：`com.jetpiggy.ginput`。
- Gradle 用 Kotlin DSL。
- 不支援開機後第一次解鎖前使用（Direct Boot）；那段時間系統會暫時改用其他輸入法。

## 發佈

- 暫時只發佈 APK，不上架 Google Play（2026-10-13）：APK 放在這個 repo 的 GitHub Releases，檔名固定是 `GInput.apk`；README 的「下載最新版 APK」連到 `releases/latest/download/GInput.apk`，一直下載到最新版。
- Google Play（日後上架用）：
  - 桌面名稱「GInput」，商店標題「GInput 中英混打輸入法」，分類「工具」。
  - App 圖示：JetPiggy 飛豬坐著單蹄點藍色小鍵盤，品牌青綠底；Android 13 起有單色主題圖示。由 `tools/icon/build_icon.py` 產生。
  - 在 Play Console 建立 App 時上傳自己的簽章金鑰。Play 版和 GitHub Releases 的 APK 用同一把。
- 網站 <https://ginput.jetpiggy.com/>：用 Cloudflare 發佈下載頁、私隱政策和 `latest.json`；APK 放在這個 repo 的 GitHub Releases。
- 更新提示：只在不是從 Play 安裝的版本顯示「有新版本」；按鈕交給瀏覽器下載最新的 APK（`latest.json` 的 `pageUrl`），不在 App 內下載和安裝。
  - 打開設定 App 時讀一次 `latest.json`（由子頁返回主頁不再讀）；鍵盤打開時也讀，但距離上次讀到要超過一日（失敗的話隔一小時再試）。請求的 User-Agent 只寫「GInput」。
  - `versionCode` 比手機上的大，才在設定主頁最上面顯示版本、更新內容和「下載新版本」。
  - 下載連結一定要是 https；連線或格式有問題就當作沒有新版本。
  - 讀到的 `latest.json`、上次讀到的時間，以及看過和關掉的記錄存在 noBackupFilesDir，不備份。
- 公告：`latest.json` 可以帶 `notice`（編號、中英文文字、可選的 https 連結），同樣只在不是從 Play 安裝的版本顯示。設定主頁最上面顯示「GInput 公告」、文字、「了解更多」（有連結時）和「知道了」；按「知道了」之後這個編號不再顯示。
- 鍵盤的小點：有未在設定主頁看過的新版本或公告，工具列的「設定」圖示右上角加一個小點；打開設定主頁看過就消失。不彈窗，不打擾打字。
- 新版簡介：更新了 GInput 之後，第一次在一般文字框打開鍵盤時，按鍵區顯示一次這個版本的簡介：標題「GInput 已更新到 X.Y.Z」和兩三項簡單的改動；按「知道了」回到按鍵，之後不再顯示。
  - 全新安裝不顯示。密碼欄位和數字鍵盤不顯示，等下次在一般文字框打開鍵盤。
  - 只寫使用者看得到的改動。新版本沒有這類改動，就不更新簡介，看過的人不會再看到。
- 版本號：內部測試用 0.x，正式上架用 1.0。
- 原始碼：<https://github.com/JetPiggy/GInput>，以 Apache License 2.0 授權，品牌圖像除外（ADR 0007）。
