# 速成和倉頡的符號碼跟 Windows 的 zx 規則，清單由 GInput 自行整理

速成和倉頡可以打標點：倉頡打 zx 加兩個字母，速成照首碼加尾碼，即 z 加最後那個字母，例如速成 zd 出「。﹏「」。碼跟 Windows 倉頡：zx 後面的兩個字母各取 a 至 y，按 Big5 的次序由 A140 排下去。只收最前面三行（A140 至 A1AC），即 74 個標點（全形空格不列出）。清單由 GInput 按這個規則自行整理，建置時和 libcangjie 核對。符號排在同一串組字的中文候選字後面，不成為記憶字，連打不用來組句，也不設開關。

## Considered Options

- 照用 libcangjie 的符號：建置字庫時本來就濾走了。它只有這三行的大約一半，缺了小型和直排標點（例如「﹚」），也有碼放錯了。
- 連 libcangjie 其他的符號碼一起收：yyy 開頭的碼照速成的首尾規則變成 y 加一個字母，會和不少中文字的速成碼重碼；za 只有五代才有；zj 開頭的是日文假名。
- 收 Big5 全部符號（數學符號、箭咀、單位、方格、全形字母、希臘字母、注音）：同一個規則可以一直排到 A3BF，但每個速成碼會由 3 個符號變成十多個，而且未能確認 Windows 有這些碼。暫時不收。
- 加一個開關：z 開頭的碼沒有中文字，影響只是兩個字母的 z? 組字多了符號，不知道這個功能的人幾乎碰不到，所以不加。

## Consequences

- 字庫要升一個版本，字的範圍多了這些標點，並標明哪些是符號，讓引擎把它們排後、不記錄、不用來組句。
- 符號沒有字頻，照 Big5 次序排，常用度次序和 Windows 次序一樣。
- 同時啟用粵拼時，za、ze、zi、zo、zu 也是粵拼；因為符號排在中文候選字後面，粵拼的字次序不變。
- 「選中文」空白鍵模式下，打兩個字母的 z? 再按空白鍵會寫入符號，不再當英文寫入；英文沒有這樣的字。
- 授權不變：碼按 Big5 的次序推出來，核對用的 libcangjie 是公有領域。
- 日後要收其餘的 Big5 符號，沿用同一個規則和清單。
