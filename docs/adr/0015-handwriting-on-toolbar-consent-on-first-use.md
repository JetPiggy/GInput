# 工具列預設有「手寫」，第一次按時才說明和同意；同意之前不初始化 ML Kit

ADR 0014 把手寫預設關閉，要在設定打開時同意，很多人不會知道有手寫。這份 ADR 改為工具列預設顯示「手寫」，同意改在第一次按「手寫」時進行，做法和翻譯、改寫第一次使用時的說明一樣。其餘沿用 ADR 0014 的全部規則：

- 輸入內容永遠不收集。
- 當機回報預設開啟，送往 Sentry，不含任何輸入內容。
- 使用統計預設關閉，首次設定時詢問。只送匿名的功能使用次數，送往我們自己的 Cloudflare Worker。
- 翻譯和改寫只在使用者每次主動按「翻譯」或「改寫」時進行，只送出要處理的那段文字，經我們自己的 Cloudflare Worker 轉給 AI 服務，並在第一次使用時寫明會送往哪個服務。
- Worker 不記錄送來的文字；選用的 AI 服務不可以用這些文字訓練模型。
- 手寫（ADR 0013）：
  - 工具列預設有「手寫」（密碼欄位沒有），可以在設定的「輸入方案」關掉。
  - 第一次按「手寫」，手寫板先顯示說明：寫的字只在手機上辨識；按「開啟」會從 Google 下載約 26 MB 的香港中文手寫模型；ML Kit 會把診斷資料送往 Google，GInput 關不掉；不想用可以在設定關掉手寫。按「開啟」才算同意。按返回鍵離開就甚麼都不做，下次按「手寫」再顯示說明。
  - 同意之前，App 完全不初始化 ML Kit，不下載，也不傳送任何東西。GInput 自己記住使用者有沒有同意，不用問 ML Kit 模型下載了沒有。
  - 手寫的筆跡和辨識結果只在手機上處理，不會送出。ML Kit 辨識時參考游標前的文字，這些文字也只在手機上用。
  - ML Kit 送往 Google 的診斷資料：手機型號和 Android 版本、App 的套件名稱和版本、每次安裝不同的識別碼、效能數字、設定、輸入和輸出的大小、出錯代碼，以及設定的語言。
  - 在設定關掉手寫就刪除模型，之後不再使用 ML Kit；再打開要重新同意。

這份 ADR 取代 ADR 0014。

## Considered Options

- 手寫預設開啟，不問：最多人用得到，但未經同意就把診斷資料送給 Google，和 GInput 其餘「預設不送、問了才送」的做法不一致。
- 預設關閉，在設定打開時同意（ADR 0014）：私隱最穩妥，但很多人不會打開設定，也就不知道有手寫。
- 首次設定精靈問一次：新使用者會見到，但舊使用者升級後不會見到；而且在未試過手寫之前就要決定。
- 工具列預設有「手寫」，第一次按時才同意（採用）：人人看得到，有興趣才按；同意之前不初始化 ML Kit，所以沒有按過的人不會傳送任何東西。ADR 0014 當時以為要先初始化 ML Kit 才知道模型下載了沒有；其實 GInput 自己記住有沒有同意就夠，未同意的話，模型一定沒有下載（App 啟動時會清走 ML Kit 留下的檔案）。

## Consequences

- 設定分成兩項：工具列有沒有「手寫」（預設開啟），以及有沒有同意說明（預設未同意）。只有兩項都是「是」才可以用 ML Kit。在設定關掉手寫，同意也一併取消。
- 1.0.1 之前未發佈的版本用 `handwriting` 這個鍵表示「打開並同意」；新版用新的鍵，舊的值不再讀取。
- App 啟動時，只要不可以用 ML Kit（關了手寫或未同意），就清走 ML Kit 留下的模型、紀錄、識別碼和未送出的診斷資料，並取消它排了的背景工作。
- ML Kit 不提供下載進度：手寫板和設定頁按 ML Kit 資料夾的大小，和下載完的大小（約 26 MB）比較，顯示下載了幾多百分比；未完成前最多顯示 99%。
- 私隱政策和 Play 的資料安全表格：「App 資訊和效能 → 診斷」和「裝置或其他 ID」仍然由 ML Kit 收集、屬可選（使用者第一次按「手寫」並同意才收集），但寫法要由「在設定打開手寫」改為「第一次使用手寫時同意」。
- 沿用 ADR 0014：App 不用 ML Kit 自動初始化的 provider，WorkManager 也是 ML Kit 用時才初始化；ML Kit 的識別碼和紀錄不備份；當機報告和日誌不可以帶有輸入內容。
