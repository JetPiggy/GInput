# 哪些資料會離開手機

輸入法看得到使用者輸入的一切，但公開上架的 App 也需要知道當機原因，所以 GInput 宣告網路權限，同時嚴格限定哪些資料可以離開手機：

- 輸入內容永遠不收集。
- 當機回報預設開啟，送往 Sentry，不含任何輸入內容。
- 使用統計預設關閉，首次設定時詢問。只送匿名的功能使用次數，送往我們自己的 Cloudflare Worker。
- 翻譯只在使用者每次主動按「翻譯」時進行，只送出要翻譯的那段文字，並在第一次使用時寫明會送往哪個服務。

## Considered Options

- 完全不宣告網路權限：最能取信使用者，但公開上架後無從得知當機原因，也做不到雲端翻譯。
- Firebase Crashlytics 和 Analytics：最省事，但鍵盤裏內置 Google 的分析 SDK，私隱觀感差。
- 全部自建（ACRA 加自己的 Worker）：資料全在自己手上，但當機報告的分組和還原混淆的堆疊都要自己做。

## Consequences

- 當機報告和日誌不可以帶有輸入內容，包括使用者正在哪個 App 打字。程式要主動過濾，不能只靠 SDK 的預設值。
- Android 備份只包括設定、常用短語和自定詞彙，送往使用者自己的 Google 帳號；剪貼簿歷史不備份。
- 翻譯服務選定後，私隱政策要寫明該服務保留資料多久。
