# 用組字，不直接寫入

GInput 打出的字母先作為組字顯示在文字框裏（帶底線）。按候選字就換成中文；按空白鍵、標點或 Enter，才把字母當英文寫入。Kaiboard 是把字母直接寫進文字框，選中文時再刪掉那串字母。這樣做有兩個問題：打完英文字後要先按 Ⓧ 或空白鍵清碼，而刪除已寫入的文字在部分 App 會出錯。只有在不支援組字的欄位（例如 InputType 為 TYPE_NULL 的終端機），GInput 才退回直接寫入。

## Considered Options

- 直接寫入（Kaiboard 的做法）：任何 App 都能用，打英文不用多按；但要手動清碼，換成中文時又要刪除已寫入的字母。
- 字母只在鍵盤上顯示：沒有相容問題，但打英文時字不會出現在原位，感覺不自然。

## Consequences

- 每次寫入後組字自動清空，所以不需要 Ⓧ 鍵。
- 有組字時按 Enter，只寫入字母，不換行也不送出。
- 終端機等欄位的行為和其他 App 不同，要分開測試。
