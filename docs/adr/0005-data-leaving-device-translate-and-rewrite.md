# 翻譯和改寫可以送出使用者選定的文字

輸入法看得到使用者輸入的一切，所以 GInput 嚴格限定哪些資料可以離開手機。這份 ADR 沿用 ADR 0001 的全部規則，只把例外由「翻譯」擴大到「翻譯和改寫」：

- 輸入內容永遠不收集。
- 當機回報預設開啟，送往 Sentry，不含任何輸入內容。
- 使用統計預設關閉，首次設定時詢問。只送匿名的功能使用次數，送往我們自己的 Cloudflare Worker。
- 翻譯和改寫（例如改成書面語、改成粵語口語、改語氣、改錯字）只在使用者每次主動按「翻譯」或「改寫」時進行，只送出要處理的那段文字，經我們自己的 Cloudflare Worker 轉給 AI 服務，並在第一次使用時寫明會送往哪個服務。
- Worker 不記錄送來的文字；選用的 AI 服務不可以用這些文字訓練模型。

這份 ADR 取代 ADR 0001。

## Considered Options

- 維持 ADR 0001，只准翻譯：做不到改寫，而改寫（尤其粵語口語和書面語互換）是香港使用者用得着的功能。
- 只在手機上改寫：Gemini Nano（ML Kit GenAI）只准最前景的 App 用，輸入法很可能被擋，它的改寫和校對也不支援中文；細型開放模型要下載 1.3–2.6 GB，粵語質素明顯較差。
- 翻譯和改寫用同一套規則，經自己的 Worker 送往雲端 AI 服務（採用）。

## Consequences

- 私隱政策和 Play 的資料安全表格要寫明翻譯和改寫會送出文字、送往哪個服務、服務保留資料多久。
- 選 AI 服務時，排除會用 API 輸入訓練模型的服務，例如 DeepSeek 直連（私隱政策寫明可能用輸入訓練模型，資料存放在中國）。
- `AGENTS.md` 的硬規則改為「唯一的例外是使用者主動按『翻譯』或『改寫』時送出的那段文字」。
- 其餘同 ADR 0001：當機報告和日誌不可以帶有輸入內容，包括使用者正在哪個 App 打字；Android 備份只包括設定、常用短語和自定詞彙，剪貼簿歷史不備份。
