# 手寫打開後，ML Kit 會把診斷資料送往 Google；寫的字不離開手機

輸入法看得到使用者輸入的一切，所以 GInput 嚴格限定哪些資料可以離開手機。這份 ADR 沿用 ADR 0005 的全部規則，加上手寫：

- 輸入內容永遠不收集。
- 當機回報預設開啟，送往 Sentry，不含任何輸入內容。
- 使用統計預設關閉，首次設定時詢問。只送匿名的功能使用次數，送往我們自己的 Cloudflare Worker。
- 翻譯和改寫（例如改成書面語、改成粵語口語、改語氣、改錯字）只在使用者每次主動按「翻譯」或「改寫」時進行，只送出要處理的那段文字，經我們自己的 Cloudflare Worker 轉給 AI 服務，並在第一次使用時寫明會送往哪個服務。
- Worker 不記錄送來的文字；選用的 AI 服務不可以用這些文字訓練模型。
- 手寫（ADR 0013）預設關閉。使用者在設定打開時，先說明會傳送甚麼，按「開啟」後才生效：
  - 手寫的筆跡和辨識結果只在手機上處理，不會送出。ML Kit 辨識時參考游標前的文字，這些文字也只在手機上用。
  - 打開時從 Google 下載香港中文的手寫模型。
  - ML Kit 會把診斷資料送往 Google：手機型號和 Android 版本、App 的套件名稱和版本、每次安裝不同的識別碼、效能數字、設定、輸入和輸出的大小、出錯代碼，以及設定的語言。GInput 關不掉這部分，所以要使用者打開時同意。
  - 關掉手寫就刪除模型，之後不再使用 ML Kit。

這份 ADR 取代 ADR 0005。

## Considered Options

- 手寫預設開啟：最多人用得到，但未經同意就傳送診斷資料給 Google，和 GInput 其餘「預設不送、問了才送」的做法不一致。
- 第一次打開手寫板才說明（像翻譯和改寫）：工具列會一直有「手寫」，而 ML Kit 要在使用者同意之前已經初始化，才能判斷模型下載了沒有。
- 預設關閉，在設定打開時說明和同意（採用）：未打開手寫的人，App 完全不初始化 ML Kit，也不會傳送任何診斷資料。

## Consequences

- 私隱政策和 Play 的資料安全表格要加上手寫：「App 資訊和效能 → 診斷」和「裝置或其他 ID」由 ML Kit 收集，屬可選（使用者打開手寫才收集），送往 Google；寫的字不收集。
- App 不用 ML Kit 自動初始化的 provider（`MlKitInitProvider`），改為手寫打開後才初始化。WorkManager 也不在 App 啟動時初始化（移除 `WorkManagerInitializer`），ML Kit 用時才初始化。
- ML Kit 刪除模型時留下共用的檔案、紀錄、每次安裝不同的識別碼和未送出的診斷資料；手寫關閉時，App 在下次啟動時（未初始化 ML Kit 之前）全部刪除，並取消它排了的背景工作。
- ML Kit 的識別碼和紀錄放在 SharedPreferences，所以備份規則改為逐個列出設定和常用短語的檔案，不再包括整個 SharedPreferences。
- ML Kit 連帶加入網絡狀態和 wake lock 兩項普通權限，都是安裝時自動給予的。WorkManager 帶來的開機啟動和前景服務權限從 manifest 移除。
- `AGENTS.md` 的硬規則加上手寫：寫的字不離開手機，ML Kit 的診斷資料要使用者打開手寫時同意。
- 其餘同 ADR 0005：當機報告和日誌不可以帶有輸入內容，包括使用者正在哪個 App 打字；Android 備份只包括設定、常用短語和自定詞彙，剪貼簿歷史不備份。
